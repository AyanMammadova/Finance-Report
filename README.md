# Maliyyə Göstəricilərinin və Xərclərin Təhlili | Power BI

Bu layihədə büdcə üzrə gəlir və mənfəət, xərclər və müştəri məmnuniyyəti məlumatları əsasında interaktiv Power BI hesabatı hazırlanıb. Hesabat maliyyə göstəricilərini şöbələr, müştərilər, aylar və regionlar üzrə araşdırmağa imkan verir.

## Layihənin Məqsədi

Əsas maliyyə göstəricilərini bir paneldə toplamaq, şöbələr üzrə gəlir və xərcləri müqayisə etmək, aylıq göstəriciləri və müştərilər üzrə mənfəəti vizuallaşdırmaq.

## Hesabatın Məzmunu

- Büdcə üzrə ümumi gəliri və mənfəəti göstərən kartlar.
- Ümumi xərcləri və orta müştəri məmnuniyyətini göstərən kartlar.
- Şöbələr üzrə büdcə gəlirini, büdcə mənfəətini və xərcləri müqayisə edən cədvəl.
- Şöbələr üzrə büdcə gəlirini göstərən çubuq diaqramı.
- Beş ay üzrə büdcə gəlirini və mənfəətini müqayisə edən sütun diaqramı.
- Seçilmiş beş müştəri üzrə büdcə mənfəətini göstərən çubuq diaqramı.
- Ay və region üzrə seçim etməyə imkan verən filtrlər.

## İstifadə Olunan Alətlər və Bacarıqlar

- Microsoft Power BI Desktop
- DAX ölçüləri
- Maliyyə məlumatlarının təhlili
- Məlumatların vizuallaşdırılması
- İnteraktiv filtrləmə
- Şərti rəngləmə

## Hesabatı Necə Açmaq Olar?

1. Bu repozitoriyadan `FinanceReport.pbix` faylını yükləyin.
2. Faylı Microsoft Power BI Desktop proqramında açın.
3. Ay və region filtrləri ilə araşdırmaq istədiyiniz məlumatları seçin.
4. Qrafiklərdəki elementlərə klikləyərək əlaqəli göstəriciləri müqayisə edin.

GitHub-da hesabatın ekran görüntüsünə baxmaq mümkündür. İnteraktiv imkanlardan istifadə etmək üçün `.pbix` faylını Power BI Desktop proqramında açın.
